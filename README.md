# 📊 Bangalore Tech Salary Decoder

A Python-based data analytics project that analyzes salary trends of Bengaluru tech professionals using **Pandas** and **NumPy**.

This project was completed as part of **The Unlox Academy – 2-Hour Live Project**.

---

## 📌 Project Overview

The main objective of this project is to clean, analyze, and generate business insights from a salary dataset of Bengaluru tech professionals.

The project includes:

- Data Cleaning
- Data Analysis
- Salary Distribution Analysis
- Experience-based Salary Growth
- Skill Premium Analysis
- Company Type Salary Comparison
- Underpaid Employee Detection
- Final Business Report

---
